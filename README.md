# 🦔 Alice Telegram News Parser

Приватный webhook-сервер для интеграции публичных Telegram-каналов с умными колонками Яндекса (Алиса). 

Этот микросервис парсит веб-версию Telegram-канала (на примере `t.me/s/ejlabru`), извлекает свежие новостные сводки по ключевым словам (Утро, День, Вечер), очищает текст от визуального мусора (эмодзи, ссылки) и отдает его Алисе в формате, оптимизированном для голосового чтения (TTS).

## 🌟 Особенности
- **Работа без Telegram API:** Использует парсинг публичной веб-версии (`t.me/s/...`), не требует токенов и авторизации.
- **Умная обрезка текста:** Автоматически обрезает длинные посты до лимита Яндекс.Диалогов (1024 символа), находя последнюю точку, чтобы Алиса не обрывалась на полуслове.
- **Очистка контента:** Вырезает URL-адреса и служебные символы для чистого звучания диктора.
- **Docker-ready:** Полностью готов к деплою на любой сервер одной командой.

## 🛠 Стек технологий
- Python 3.11+
- [FastAPI](https://fastapi.tiangolo.com/) + Uvicorn (Web-сервер)
- [BeautifulSoup4](https://www.crummy.com/software/BeautifulSoup/bs4/doc/) (Парсинг HTML)
- Docker & Docker Compose

## 🚀 Локальный запуск (для разработки)

Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <url-вашего-репозитория>
   cd alice_news_bot
   ```
Создайте виртуальное окружение и установите зависимости:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
Запустите локальный сервер:

`uvicorn main:app --port 8000 --reload`
Для тестирования с серверами Яндекса пробросьте порт через ngrok:

`ngrok http 8000`
Полученную HTTPS-ссылку (например, https://1234-abcd.ngrok-free.app/alice) используйте в консоли Яндекс.Диалогов.

🐳 Развертывание на сервере (Docker)
Проект настроен для быстрой сборки и запуска в фоне с помощью Docker.

Убедитесь, что на сервере установлены docker и docker-compose.

В корневой папке проекта выполните команду:

`docker compose up -d --build`
Сервер запустится на порту 8000 внутри сервера (127.0.0.1:8000). Для вывода наружу рекомендуется использовать Nginx (в качестве reverse proxy) и Certbot для получения бесплатного SSL-сертификата (требование Яндекса).

# ⚙️ Настройка в Яндекс.Диалогах
1. Перейдите в Консоль разработчика Яндекс.Диалогов.

2. Создайте новый «Навык в Алисе».

3. В разделе Backend выберите Webhook и укажите URL вашего сервера:
https://ваш-домен.ru/alice (обязательно с /alice на конце).

4. Укажите активационное имя (например, «Сводка новостей»).

**⚠️ Важно: В самом низу настроек поставьте галочку «Приватный навык», чтобы обойти модерацию и слушать новости только на своих устройствах.**

5. Добавьте логотип

6. Нажмите «Сохранить» и «Опубликовать».

# 🗣 Использование (Голосовые команды)
* Запустите навык на колонке командой:

* «Алиса, запусти [название навыка]»

* Внутри навыка поддерживаются следующие команды:

* «За утро/день/вечер» — озвучит последний утренний/дневной/вечерний пост.
